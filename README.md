# Youneng Bao — Academic Homepage

A lightweight, multi-page academic website hosted with GitHub Pages.

- `index.html` — profile and news
- `biography.html` — biography, research interests, experience, and service
- `publications.html` — searchable and filterable publication list
- `people.html` — lab members and research focus
- `jemdoc.css` — shared visual style
- `site.js` — shared interactions

The site uses plain HTML, CSS, and JavaScript and requires no build step.
